Ejercicio 35: Convertidor de Tiempo

Convierte una cantidad de segundos en formato legible: horas, minutos y segundos restantes.

0
Horas
0
Minutos
0
Segundos
¿Cómo funciona?
Usa división entera (/) y módulo (%):
• Horas: segundos / 3600
• Minutos: (segundos % 3600) / 60
• Segundos: segundos % 60
